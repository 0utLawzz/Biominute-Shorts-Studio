# Contributing to BioMinute Shorts Studio

## Setup

See [`docs/INSTALL.md`](docs/INSTALL.md) and [`docs/RUN.md`](docs/RUN.md).

```bash
git clone https://github.com/0utLawzz/biominute-shorts-studio.git
cd biominute-shorts-studio
pnpm install
```

## Guidelines

- Use **pnpm** only.
- Prefer focused PRs; update `PROGRESS.md` / `VERSION.md` when changing pipeline behavior.
- Do not commit production credentials or client media with PII.
